About

This repository contains a collection of AI master instructions designed to help AI assistants create, develop, and improve digital projects.

The instructions allow AI to work with different programming languages, frameworks, libraries, and technologies depending on the requirements of each project.

The goal is to produce functional, optimized, and well-structured results rather than incomplete demonstrations or visual-only mockups.

AI is free to use any suitable programming language, including:

Additional languages may be used when necessary.

Core Principles

- Functionality: Build features that actually work.
- Flexibility: Do not restrict development to one programming language.
- Performance: Optimize projects for their target devices.
- Security: Follow appropriate security practices.
- Responsiveness: Support mobile, tablet, and desktop.
- Code Quality: Keep source code organized and maintainable.
- Creativity: Explore better solutions without changing the user's main idea.

Development Guidelines

Every project should aim to include:

1. Project architecture and folder structure.
2. Complete source code.
3. Required dependencies.
4. Installation instructions.
5. Execution instructions.
6. Testing and debugging guidance.
7. Deployment instructions when applicable.

Android Compatibility

When the user develops projects using an Android phone, the AI should:

- Provide mobile-friendly instructions.
- Support Termux workflows when appropriate.
- Avoid unnecessary desktop-only requirements.
- Consider limited RAM and processing power.
- Explain how to create, edit, and run project files.

How to Use

1. Download or open the master prompt file.
2. Copy the complete instructions.
3. Paste them into your preferred AI assistant.
4. Describe your project requirements.
5. Let the AI select appropriate technologies.
6. Review and test the generated project.

Project Philosophy

Technology should not limit creativity.

The best solution is not necessarily the most complicated one. It is the solution that works reliably, meets the requirements, and can be maintained.
